机组和机务标准通讯用语指南

发动机启动和推拖飞机期间的标准通讯流程

标准通讯程序概述

本指南汇总了波音和空客飞机在发动机启动和推拖期间，机组和机务人员之间的标准通讯用语，符合ICAO、FAA、EASA和CAAC等民航监管机构的规定。

为什么需要标准通讯？

标准通讯用语可以确保:

  • 减少误解和通讯错误
  • 提高地面操作的安全性
  • 确保各方对操作步骤有明确一致的理解
  • 符合国际和国家民航局的规定要求

通讯方式

  • 对讲机通讯 (机组 - 机务)
  • 标准手势信号
  • 地面引导信号
  • 无线电通讯 (与ATC)

主要操作阶段

  • 推出前准备
  • 推出操作
  • 发动机启动
  • 拖曳操作
  • 完成操作和设备断开

波音和空客飞机通讯差异

虽然基本通讯原则相同，但波音和空客飞机在某些程序和术语上存在以下主要差异：

特点 波音飞机 空客飞机
发动机启动顺序 通常先2号发动机，后1号发动机 通常先1号发动机，后2号发动机
启动程序命令语 "START ENGINE (number)" "STARTING ENGINE (number)"
推出后程序 明确强调"SET PARKING BRAKE" 使用"BRAKES SET"确认

标准通讯程序

通讯基本原则

  • 使用简洁、明确的语言和术语
  • 确保发出的指令得到明确的回复确认
  • 不使用非标准术语或非正式表达
  • 说话速度保持适中，使信息清晰可辨
  • 当对指令有疑问时，立即请求澄清
  • 使用标准的术语和短语，避免自创表达

通讯结构

对话开始

机务: "驾驶舱，地面呼叫"

机组: "地面，驾驶舱收到"

对话结束

机务: "设备已断开，现在可以滑行"

机组: "设备断开明白，开始滑行"

异常情况通讯

当任何一方发现安全隐患需要立即停止操作时：

通讯方 标准用语 含义
机组/机务 "STOP! STOP! STOP!" 立即停止所有操作
机务 "SET PARKING BRAKE IMMEDIATELY" 立即设置停车刹车
机组 "BRAKES SET" 刹车已设置

紧急情况下，任何一方都可以直接发出停止命令，对方必须立即执行，无需等待解释。

当发现发动机启动异常时：

通讯方 标准用语 含义
机务 "ABNORMAL START, ENGINE (X)" X号发动机启动异常
机组 "ABORTING START" 正在中止启动
机务 "FIRE INDICATION, ENGINE (X)" X号发动机有火警指示
机组 "ACTIVATING FIRE SUPPRESSION" 激活灭火系统

波音飞机通讯程序

波音系列飞机的标准通讯

波音飞机（如737、747、777、787等）在发动机启动和推拖操作中有一套特定的通讯程序。以下是波音飞机的标准通讯流程和术语：

发动机启动程序

关键特点

  • 波音飞机通常先启动2号发动机，后启动1号发动机
  • 使用ENGINE START开关，位置为GRD（地面启动）
  • 需要监控N1、N2、EGT和燃油流量等关键参数
  • 使用"STARTER CUTOUT"通报自动断开启动程序

标准启动程序通讯顺序

  1. 机组宣布："Start ENGINE NUMBER (X)"
  2. 机务确认："Clear to start"
  3. 机务报告："N1 rotation"
  4. 机组在适当时机宣布："STARTER CUTOUT"
  5. 机务确认："ENGINE (X) STABILIZED"

波音737发动机启动标准对话

机务： "Cockpit, ground. All doors and panels closed, ready for engine start."

机组： "Ground, cockpit. Starting right engine."

机务： "Clear to start right engine."

机务： "Right engine N1 rotation."

机组： "STARTER CUTOUT."

机务： "Right engine stabilized."

机组： "Starting left engine."

机务： "Clear to start left engine."

机务： "Left engine N1 rotation."

机组： "STARTER CUTOUT."

机务： "Left engine stabilized."

波音飞机推出程序

关键程序要点

  • 明确建立与地面人员的通讯
  • 推出过程中不使用飞机刹车停止飞机
  • 按地面人员指示操作刹车
  • 推出完成后设置停车刹车

波音飞机推出标准用语

  • 机组请求推出： "Request pushback"
  • 机务确认刹车： "Confirm parking brakes set"
  • 机组回应： "Parking brakes set"
  • 推出前释放： "Release parking brakes"
  • 机组确认： "Parking brakes released"
  • 推出完成： "Pushback complete, set parking brakes"
  • 机组回应： "Parking brakes set"

波音推出标准对话示例（波音737）

机组： "Ground, cockpit, request pushback."

机务： "Cockpit, ground, confirm parking brakes set."

机组： "Ground, cockpit, parking brakes set."

机务： "Cockpit, ground, prepare for pushback, release parking brakes when ready."

机组： "Ground, cockpit, parking brakes released."

机务： "Commencing pushback."

机务： "Pushback complete, set parking brakes."

机组： "Parking brakes set."

机务： "Parking brakes set, disconnecting tow bar."

机务： "Tow bar disconnected, bypassing pin removed, clear to disconnect headset."

机组： "Clear to disconnect, thank you for your service."

波音飞机拖曳程序

拖曳注意事项

  • 必须确保转向系统解锁
  • 明确转向销的状态（已插入/已拔出）
  • 按照特定路线拖曳时，需要明确转向方向
  • 确保拖曳期间刹车正确使用

拖曳标准用语

  • 确认拖曳许可： "Tow approved via (routing)"
  • 确认转向状态： "Confirm steering bypass pin inserted"
  • 确认刹车状态： "Confirm parking brakes released"
  • 转向指令： "Turning left/right"
  • 拖曳完成： "Tow complete, set parking brakes"

空客飞机通讯程序

空客系列飞机的标准通讯

空客飞机（如A320、A330、A350等）在发动机启动和推拖操作中有一套特定的通讯程序。以下是空客飞机的标准通讯流程和术语：

发动机启动程序

关键特点

  • 空客飞机通常先启动1号发动机，后启动2号发动机
  • 在IGN/START位置使用ENGINE MODE选择器
  • 使用ENG MASTER开关从OFF切换到ON
  • 监控N1、N2以及EGT的变化

启动程序通讯顺序

  1. 机组宣布："Engine (X) Start"
  2. 机务确认："Clear to start engine (X)"
  3. 机务报告："N1/N2 rotation"
  4. 机务确认："Engine (X) parameters normal"
  5. 启动下一台发动机重复上述步骤

A320发动机启动标准对话

机务： "Cockpit, ground, all doors and panels closed, ready for start."

机组： "Ground, cockpit, starting engine one."

机务： "Engine one clear to start."

机务： "Engine one N2 rotation."

机务： "Engine one parameters normal, stabilized."

机组： "Starting engine two."

机务： "Engine two clear to start."

机务： "Engine two N2 rotation."

机务： "Engine two parameters normal, stabilized."

机组： "Both engines stable, normal parameters."

空客飞机推出程序

关键程序要点

  • 确认机轮挡块已经移除
  • 依照指示确认刹车状态
  • 推出途中确认转向系统旁通销状态
  • 推出完成后确认刹车设置

空客推出标准用语

  • 机务准备推出： "Ground to cockpit, chocks removed, ready for pushback"
  • 确认刹车： "Confirm brakes released"
  • 机组回应： "Brakes released"
  • 开始推出： "Commencing pushback"
  • 推出完成： "Pushback complete, set brakes"
  • 机组回应： "Brakes set"

A320推出标准对话

机组： "Ground, cockpit, request push and start."

机务： "Cockpit, ground, chocks removed, ready for pushback."

机务： "Confirm brakes released."

机组： "Brakes released."

机务： "Commencing pushback."

机务： "Pushback complete, set brakes."

机组： "Brakes set."

机务： "Disconnecting tow bar."

机务： "Tow bar disconnected, bypassing pin removed, all clear."

机组： "Roger, thank you."

空客飞机拖曳程序

拖曳注意事项

  • 确认转向系统旁通销已经插入
  • 清晰表明预计拖曳路线和方向
  • 在拖曳过程中使用标准转向术语
  • 保持持续通讯，尤其是转向时

拖曳标准用语

  • 确认旁通销： "Confirm NWS bypass pin in towing position"
  • 确认拖曳路线： "Towing via (routing details)"
  • 确认刹车： "Confirm brakes released"
  • 转向指示： "Turning left/right"
  • 拖曳完成： "Tow complete, set brakes"

空客特有的拖曳注意事项

空客飞机要求在拖曳操作中特别注意转向系统状态。A320系列飞机会在ECAM上显示"NWS DISC"信息，当转向旁通销安装在拖曳位置时。如果显示此信息但地面人员确认转向销处于拖曳位置，则请勿在推出过程中启动发动机。

波音与空客比较

操作项目 波音飞机 空客飞机
发动机启动顺序 通常先启动2号发动机，后启动1号发动机 通常先启动1号发动机，后启动2号发动机
启动宣布用语 "Start ENGINE NUMBER (X)" "Starting ENGINE NUMBER (X)"
启动系统控制 ENGINE START switch to GRD ENGINE MODE selector to IGN/START
推出刹车用语 "Parking brakes set/released" "Brakes set/released"
启动顺序确认 "STARTER CUTOUT" 由机务报告"Parameters normal"
转向系统术语 "Steering bypass pin" "NWS bypass pin"

标准手势信号

ICAO标准地面操作手势

当无法使用对讲机通讯时，标准手势信号是机组和地面人员之间重要的通讯方式。以下是推出和发动机启动过程中常用的标准手势：

手势信号重要性

  • 提供视觉通讯备份方式
  • 确保在设备故障情况下能够继续安全操作
  • 减少因语言差异导致的误解
  • 在环境噪音大的情况下确保清晰通讯

手势标准化

  • ICAO已经制定标准手势，载于附件2
  • 适用于全球所有使用ICAO标准的机场
  • 为防止混淆，禁止使用非标准手势
  • 航空公司可以基于这些标准制定详细程序

推出和拖曳相关手势

刹车设置

手臂在胸前，手握拳，表示设置刹车

刹车释放

手臂在胸前，手掌打开，表示释放刹车

开始后推

双臂向外伸展，然后向身体方向收回

转向（尾部向右）

左手向下指，右手重复上抬动作

转向（尾部向左）

右手向下指，左手重复上抬动作

正常停止

双臂完全伸展，掌心朝前

紧急停止

双臂快速交叉过头顶

插入轮挡

双臂向下，掌心相对，做插入动作

发动机启动相关手势

启动发动机

右手绕头部做圆周运动，同时左手指向相应发动机

切断发动机

右臂前伸，手在颈部前做切割动作

减速发动机

手臂下垂，掌心向地面，然后上下移动

减速指定发动机

手臂下垂，掌心向地面，一只手上下移动指示相应发动机减速

APU已连接

右手平举做插入动作，左手比OK手势

APU已断开

右手平举做拔出动作，左手比OK手势

肯定（一切正常）

右臂抬至头部高度，拳头紧握，拇指向上

否定（不正常）

右臂抬至头部高度，拳头紧握，拇指向下

注意事项

  • 确保在夜间操作时手势清晰可见，必要时使用荧光棒
  • 机组人员应确认理解所有手势，有疑问时立即寻求澄清
  • 所有参与地面操作的人员应接受标准手势培训
  • 紧急情况下，紧急停止信号应立即被执行，无需解释

规章标准

国际和国内标准

以下是与飞机地面操作通讯相关的主要国际和国内标准规范：

ICAO为飞机地面操作通讯制定了全球标准：

  • ICAO Doc 9432 - 《无线电通讯手册》，提供标准无线电通讯用语
  • ICAO Doc 4444 - 《空中交通管理》，包含推出和滑行通讯标准
  • ICAO Annex 2 - 《空中规则》，包含标准手势信号
  • ICAO Annex 10 - 《航空电信》，对无线通讯标准进行规范

ICAO官方网站

CAAC制定了符合ICAO标准并适用于中国民航的相关规定：

  • CCAR-121 - 《运输航空公司运行合格审定规则》，对地面操作通讯有相关要求
  • AP-135-FS-2012-03 - 《中国民航无线电通讯规程》，规范地面通讯用语
  • AC-91-FS - 《航空器地面运行指南》，对地面操作安全通讯提出要求
  • AC-120 - 《飞行运行手册》，要求航空公司建立标准通讯程序

CAAC官方网站

FAA的相关标准包括：

  • AC 00-65A - 《牵引杆和无牵引杆飞机移动》，规范推拖操作通讯
  • FAA Order 7110.65 - 《空中交通管制》，包含地面通讯程序
  • AC 120-57A - 《地面操作审定规范》，对地面操作通讯提出要求
  • AC 00-34B - 《航空器操作手势》，规范手势信号

FAA官方网站

EASA的相关标准包括：

  • EASA AMC1 CAT.OP.MPA.130 - 《商业航空运输-无线电通讯》，规范地面通讯
  • EU 965/2012 - 《欧盟航空运行法规》，对地面操作通讯有相关规定
  • SERA.14001 - 《标准欧洲航空规则》，规范无线电通讯程序
  • EASA SIB 2018-10 - 《地面操作安全信息公告》，提供通讯最佳实践

标准遵循要求

航空公司义务

  • 建立符合国际和国内标准的通讯程序
  • 编制运行手册，明确标准通讯用语
  • 确保所有机组和地面人员接受适当培训
  • 定期审核通讯程序的执行情况
  • 保持对通讯程序的更新，符合最新规定

机组和机务义务

  • 熟悉并严格遵守标准通讯用语
  • 参加定期培训和复训
  • 在操作中保持警觉，准确执行通讯程序
  • 及时报告通讯程序中的问题和改进建议
  • 在异常情况下确保明确、简洁的通讯

本指南根据波音、空客飞机手册及ICAO、CAAC、FAA、EASA等机构的规定编制
